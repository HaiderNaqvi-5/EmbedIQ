## 2024-10-24 - Accessibility improvements on Auth Pages\n**Learning:** Next.js authentication pages (login/register) lacked proper `role="alert"` for error messages, meaning screen readers would not proactively announce login failures. Additionally, many `Link` and `button` elements lacked explicit `focus-visible` styling, reducing keyboard navigability.\n**Action:** When creating form validation or API failure states, always wrap error messages in `role="alert"` and use `aria-busy` on submit buttons. Standardize focus rings using `focus-visible:ring-2 focus-visible:ring-[#D6A84F]` for consistency.
