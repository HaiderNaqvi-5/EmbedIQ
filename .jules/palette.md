## 2024-10-18 - Form Accessibillity Standardization
**Learning:** React/Next.js forms in this project frequently use dynamic error messages and asynchronous submissions but lack fundamental accessibility indicators. Specifically, dynamically rendered error divs are not announced by screen readers without `role="alert"`, and loading buttons do not convey their processing state without `aria-busy`. Furthermore, standard Tailwind focus states (`focus-visible`) were missing, which hinders keyboard navigation.
**Action:** When creating or modifying forms, always ensure error message containers use `role="alert"`, add `aria-busy={loading}` to submission buttons, and apply `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#D6A84F]/50` to interactive elements to guarantee keyboard and screen reader accessibility.
