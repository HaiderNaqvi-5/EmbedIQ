## 2024-09-16 - Color Picker Hit Areas and Accessibility
**Learning:** When building custom color pickers using native `<input type="color">`, the default click area is often small. Wrapping the input and its associated descriptive text inside a `<label>` element instantly makes the entire layout block clickable, significantly improving the hit area and usability. Additionally, because native color inputs look like static blocks, applying clear `focus-visible` styles is crucial for keyboard navigation.
**Action:** Always wrap native color inputs in a `<label>` (rather than a generic `div`) along with their text to increase the clickable area. Use `cursor-pointer` on the label and ensure the input has `focus-visible:ring-2` (or similar) to indicate focus clearly to keyboard users.
