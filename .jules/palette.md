## 2026-10-19 - Added Focus Indicators to Sidebar Navigation\n**Learning:** Keyboard accessibility (focus states) was missing on many interactive elements like Links and Buttons in the sidebar. Adding `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[#D6A84F]/50` using existing Tailwind classes provides clear, non-intrusive focus indicators for keyboard users.\n**Action:** Ensure all interactive elements, especially navigation links and critical actions like 'Sign out', receive proper focus-visible styling in the future to improve accessibility.
