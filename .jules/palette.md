## 2024-05-27 - Search Input Accessibility and Interactivity
**Learning:** Text inputs used for searching, especially those that trigger live filtering (like `Search bots...`), often lack appropriate `aria-label` attributes, making them opaque to screen reader users. Additionally, providing a direct way to clear the input (a clear button) when it has content significantly improves the interaction flow and reduces friction compared to forcing the user to manually backspace.
**Action:** Always add an `aria-label` detailing the input's specific purpose (e.g., "Search bots"). When space permits, include a conditionally rendered, accessible clear button (e.g., an `X` icon button with `aria-label="Clear search"`) inside the input, ensuring adequate right padding (`pr-10`) is set on the input to prevent text overlap.
